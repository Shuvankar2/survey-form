## 📌 About

This project is a **11-page multi-step survey form** built entirely with HTML and CSS. It was one of my early projects, built when I was learning CSS fundamentals — focused on layout, navigation flow, and responsive design without any JavaScript dependencies.

> A clean UI exercise — proving that multi-page flow and structured layouts don't always need a framework.

---

## ✨ Features

- **11-page multi-step flow** — each survey question on its own page
- **Pure HTML & CSS** — zero JavaScript, zero frameworks
- **Responsive navigation** — desktop nav + mobile hamburger menu
- **Privacy policy page** — included as a standalone page
- **Custom utility CSS** — modular stylesheet structure (`utilities.css` + `style.css`)
- **Ionicons integration** — icon support via CDN

---

## 🗂️ Project Structure

```
survey-form/
│
├── index.html          # Welcome / landing page
├── 1.html – 11.html    # Survey pages (one question per page)
├── privacy.html        # Privacy policy
├── mobile-menu.html    # Mobile navigation menu
│
├── css/
│   ├── style.css       # Core styles
│   └── utilities.css   # Reusable utility classes
│
└── img/                # Image assets
```
